## Part 3 — The gut check (score it before you sign)

**-2 = red flag, 0 = nothing special, +2 = genuinely good**

- [ ] Exclusivity is being *paid for* (royalty bump, advance, marketing) — +2
- [ ] Term is a calendar date I control — +2
- [ ] Format is narrower than "everything" — +2
- [ ] Territory is narrower than "the world" — +1
- [ ] Someone I trust read it (or a publishing attorney did) — +2
- [ ] Reversion is a letter and an email address, not a moot clause — +2
- [ ] "Exclusive" appears with no extra payment attached — −2
- [ ] Term renews *automatically* unless I cancel — −1
- [ ] "All formats, world, in perpetuity" in one sentence — −2
